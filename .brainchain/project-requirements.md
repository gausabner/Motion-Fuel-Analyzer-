# Project Requirements & Context

## 1. Vision
Transform the "Motion Fuel Analyzer" into a "Monumental, Industrial" analytics platform, inspired by the "Hudson 8" design. The goal is a high-contrast, premium feel with spacious layouts and minimalist data visualization.

## 2. The "Industrial" Aesthetic
*   **Theme:** High-Contrast.
*   **Palette:** Strict **Black (#000000)**, **White (#FFFFFF)**, and **Utility Yellow** (Accent).
*   **Density:** "Monumental" - increased padding, larger typography, breathable whitespace.
*   **Charts:** Minimalist. No grid lines. Solid black bars. distinct typograhy.

## 3. Data Mapping (The "Hudson" Protocol)
*   **Total Sales** -> `Total Spend`
*   **Units Sold** -> `Total Volume (L)`
*   **Remaining Units** -> `Active Vehicles`
*   **Units per Status** -> `Petrol vs Diesel Split` AND `Budget Utilization`

## 4. Navigation Structure
Restructure sidebar into functional groups:
*   **Analytics**
    *   Dashboard (Overview)
    *   Fleet Command
    *   Cost Centres
*   **Data Management**
    *   Fuel Logs
    *   Ingestion/Uploads
    *   System Settings

## 5. Specific Widget Requirements
*   **KPI Cards:** Must follow the specific layout of the screenshot (Icon, Label, Big Value).
*   **Status Widget:** Progress-bar style visualization for Fuel Split and Budget.
*   **Charts:** Remove "chart junk" (grids, borders). Use strong contrast.
